Act as a Senior GIS Developer. 
We need to render dynamic maps in our Streamlit dashboard based on the AI's output payload.
Architectural Decision: To handle massive spatial datasets without crashing the browser, we will not query geometries directly. Instead, we will use Folium to connect to our local GeoServer via WMS, offloading the heavy rendering to the server.
	1. The Map Helper: Create a dedicated helper module `src/frontend/map_utils.py` and write a function `render_dynamic_map(payload: dict)`. Keep this logic separated from the main Streamlit UI for better testability.
	2. Default State: If the payload is empty, return a default map centered on Florida using a light basemap (`folium.Map`).
	3. GeoServer WMS Connection: If the payload contains parameters like `layer` and `cql_filter`, dynamically connect to our local GeoServer via WMS (`folium.raster_layers.WmsTileLayer`) and add this layer to the map.
	4. Dynamic Symbology (Colors): Make the WMS layer dynamic by checking if the payload has a 'color' key (defaulting to 'FF0000'). Inject this into the WMS URL parameters (`env=color:{color}`) so GeoServer renders custom colors based on the AI's choice.
	5. The Legend Graphic: Use GeoServer's `GetLegendGraphic` API. If a layer is present in the payload, construct the legend URL and display it natively as an image (`st.image()`) in the UI.
	6. Displaying the Map: In `app.py`, replace the temporary placeholder in the left column. Use a Folium integration library (`st_folium`) to display the map generated by our helper function, passing the `frontend_payload` from the session state.
	7. Terminal Execution (`__main__` block): Inside `map_utils.py`, add an `if __name__ == '__main__':` block. Pass a mock payload to `render_dynamic_map`, generate the map, and save it to `test_map.html`. This allows us to run `python src/frontend/map_utils.py` in the terminal to instantly verify the WMS connection without booting Streamlit.
	8. Comprehensive Pytest Coverage: Create `tests/unit/test_map_utils.py`. Write tests covering three layers: Unit (verifying it defaults to Florida when empty), Integration (verifying the WMS layer is correctly appended to Folium), and Security (verifying that malicious SQL/CQL injections in the payload are properly sanitized or escaped before hitting the GeoServer URL).
